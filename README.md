
# Trade Tweaks

A lightweight RuneLite plugin that repeats incoming trade requests in the chatbox.

## Features

- Repeats incoming trade requests seven times in the chatbox.
- Can be enabled or disabled through the plugin configuration.

## Installation

Install Trade Tweaks through the RuneLite Plugin Hub.

## Configuration

**Trade Request Spam** — When enabled, incoming trade requests are repeated seven times in the chatbox.
